# VyroSprint (Lumina)

Internal Next.js dashboard for viewing and filtering customer feedback.

## Links

- **Production:** [https://vyro-sprint.vercel.app](https://vyro-sprint.vercel.app)
- **Repository:** [github.com/KBCMU/VyroSprint](https://github.com/KBCMU/VyroSprint)

## Getting Started

Run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Start editing in `src/app/page.tsx` — the page updates as you save.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) with Geist and Instrument Serif.

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Development server       |
